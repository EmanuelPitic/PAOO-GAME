# PAOO-GAME

This project is a Java-based game developed as part of the PAOO (Programarea Aplicatiilor Orientate pe Obiect) course. The game's source code is organized within the `src/PaooGame` directory.

## Features

- **Game Mechanics**: The game includes core mechanics implemented in Java, providing an interactive experience for players.

- **Resources**: All game assets, such as images and maps, are stored in the `res` directory.

- **Maps**: Three map files (`map1.txt`, `map2.txt`, `map3.txt`) define different levels or areas within the game.

- **Database Integration**: The `javaGame.db` file suggests the use of a SQLite database, possibly for storing game states, player progress, or other relevant data.

## Prerequisites

- **Java Development Kit (JDK)**: Ensure that JDK is installed on your system to compile and run the game.

- **Integrated Development Environment (IDE)**: An IDE like IntelliJ IDEA or Eclipse can be used for a more streamlined development experience.

## Getting Started

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/EmanuelPitic/PAOO-GAME.git
   ```


2. **Open the Project**:

   Open the project in your preferred IDE.

3. **Build the Project**:

   Compile the source code located in the `src/PaooGame` directory.

4. **Run the Game**:

   Execute the main class to start the game.

## Notes

- **Project Structure**:

  - `.idea` and `ScheletProiectPAOO.iml` files are related to the project's configuration in IntelliJ IDEA.

  - The `out` directory typically contains compiled classes.

- **Database Usage**:

  The presence of `javaGame.db` indicates that the game utilizes a SQLite database. Ensure that the necessary JDBC drivers are included in the project dependencies.
